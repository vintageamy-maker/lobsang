## 三個核心機制

- **簽核**：表單 → 流程（可依條件分流）→ 關卡（角色／第 N 層主管／指定人；可以會簽，也可以任一位簽）。送簽當下會存成「快照」，之後改流程設定，不影響已經在跑的單。代理人代簽時會記下「代誰簽」。
- **資料可見範圍**（`DataScopeService`）：自己／單位／全部。「能做什麼」看權限碼，「看得到誰」看組織樹和單位主管，兩件事分開管。
- **權限**：權限碼掛在角色上，登入時放進 JWT；把 `users.token_version` 加 1，那個人的舊登入就會立刻失效。

## Lobsang 業務模組

### 查書與書單（2026-11-07）

移植自 `C:\Han\book`（原本是單機版：一個 html＋PowerShell 小伺服器，清單存在瀏覽器）。

| 項目 | 內容 |
|---|---|
| 公開查書頁 | 主站 `/`（`React/src/App.tsx`），**不用登入**。兩個分頁：「用 ISBN／條碼查」、「搜尋書單」。網址帶 `?isbn=…` 會自動查，`?tab=catalog` 直接開書單 |
| 公開頁畫面 | 查詢結果和書單清單都只顯示**書名、作者（商品是品牌）、出版社、價格**（共用 `BookSummary`）；按「詳細內容」用彈窗（`DetailModal`）看全部資料，查詢結果的彈窗另含查詢來源與其他網站連結。可按「📷 掃描」用手機相機掃條碼 |
| 後台書單 | 選單「書籍 → 書單」`/books`（`ReactAdmin/src/pages/Books.tsx`）：查書、加入書單（可寫備註）、改備註、刪除；點書名或封面用彈窗看詳細資料；表格有價格欄，手機寬度（< 768px）改成「封面＋一欄文字＋操作」 |
| 後台掃描 | 「掃描」掃一本查一本；勾「查到後自動加入」就查到即加入。**「連續掃描」**：相機不關，掃到就在背景查詢並加入書單（同時最多查 3 本），相機畫面下方即時顯示結果，同一輪重複的條碼不再查，結束後列出每本結果 |
| 後台匯出 | 按「匯出」先跳視窗：篩選（關鍵字、類型、產地、加入日期、備註）、選格式（預設 Excel .xlsx，也可 CSV）、勾選欄位（全選／常用／全不選，記在瀏覽器）。Excel 全部微軟正黑體、標題列黑底白字置中並凍結、列高固定 16、條碼存文字 |
| 權限碼 | `book.manage`（書單維護）。系統管理員自動擁有；其他角色要在角色管理勾選 |
| 資料表 | `books`（migration `AddBooks`）：條碼、類型、書名、作者／品牌、出版社、出版日期、備註、`data_json`（查詢當下合併好的完整資料） |
| 公開 API | `GET /api/public/books/lookup?code=`（查外部資料庫）、`GET /api/public/books?q=&page=`（搜尋書單）—— `PublicBooksController` |
| 後台 API | `GET/POST /api/admin/books`、`GET /api/admin/books/lookup`、`PUT /api/admin/books/{id}/note`、`DELETE /api/admin/books/{id}` —— `AdminBooksController` |
| 查詢邏輯 | `Services/BookLookup/`：`CodeParser`（號碼判斷、檢查碼）、`BookLookupService`（各來源＋合併） |

**查哪些資料庫**（全部在伺服器上查，同時發出，每個欄位取第一個有值的來源）：

| 號碼 | 來源（優先順序） |
|---|---|
| 台灣書 978-957／986／626 | 國圖書號中心 → Google Books → Open Library |
| 日本書 978-4 | openBD → Google Books → Open Library |
| 其他書 | Google Books → Open Library |
| 商品條碼 | Open Food／Beauty／Products／Pet Food Facts、UPCitemdb |
| 雜誌 977、日本書下條碼 192、店內碼 2、優惠券 | 不查，只顯示說明（ISSN、定價等）和連結 |

查完會附「其他網站」連結（點了在使用者自己的瀏覽器開）：台灣書＝博客來、**誠品線上**、國圖、Google Books；日本書＝Amazon.co.jp、版元ドットコム、博客來、誠品線上、Google Books；其他＝Amazon.com、Google Books、Open Library、博客來、誠品線上。

**保護措施**：
- 公開 API 以 IP 限流：查外部資料庫 **每分鐘 20 次**、搜尋書單每分鐘 60 次，超過回 429。後台的查詢不限流
- 查到的結果在記憶體快取 6 小時、查不到的快取 10 分鐘（重開 API 就清掉）
- 書單的「備註」只有後台看得到，公開 API 不回傳
- Google Books 金鑰放伺服器設定 `BookLookup:GoogleApiKey`，使用者看不到
