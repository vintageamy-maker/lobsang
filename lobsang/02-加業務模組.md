# 加業務模組（照做清單）

← [[00-專案首頁]]

Lobsang 的共用功能來自 Base。加自己的功能時，下面這些地方**要一起改**，漏改的話通常不會報錯，而是畫面上悄悄少東西，或者權限出問題。

## 要一起動的地方

| 加了什麼 | 也要改 |
|---|---|
| 新權限碼 | `DbSeeder.PermissionSeed`；要給標準角色時用 `GrantOnceAsync`（只給一次，客戶拿掉後不會長回來） |
| 新頁面 | `DbSeeder` 用 `EnsureMenuAsync` 加選單（以路徑判斷，不會重複）；前端 `main.tsx` 加路由；圖示要加在 `icons.tsx` |
| 新表單（用表單引擎） | `DbSeeder` 種 `FormDefinition`，加上預設流程和關卡 |
| 有自己簽核快照表的單據（例如請假） | `ApprovalResolver` 加 Resolve…StepsAsync；`UserDeactivationService`（ApprovalDocType、Inspect、Reassign 三處）；首頁待辦 `AdminDashboardController` |
| 新資料表有 `OrgUnitId` | `AdminOrgUnitsController.HistoryUsageAsync`（不然刪單位時，紀錄會失去單位） |
| 新的附件分類 | `FileCategory`（**加在最後面**）＋ `FileAccessPolicy`；敏感資料不可以沿用 `Record` 分類 |
| 要發 LINE 通知 | 呼叫 `LineMessagingClient.NotifyUserAsync(userId, text)`（沒綁定或 LINE 停用會自動略過，不會出錯） |
| LINE 裡可以用的功能 | `Auth/LineSessionPolicy.cs` 的權限和路由白名單 |
| 敏感頁面（要二次驗證） | 後端端點掛 `[RequireStepUp]`，前端頁面包 `StepUpGate` |
| 保密表單（只有建立者和簽核人看得到） | `WorkRecordsController.ConfidentialCodes` |

## 改資料庫結構

1. 改 `Models/` 和 `Data/AppDbContext.cs`
2. 在 `API/Lobsang` 執行 `dotnet ef migrations add <名稱> -o Migrations`
3. 重啟 API，啟動時會自動套用到本機的 `Lobsang` 資料庫
4. ⚠ 不要手動改資料庫結構：資料庫結構以 `Migrations/` 為準，手動改會跟 migration 對不上
