# 環境與部署

← [[00-專案首頁]]

## 本機（目前唯一的環境）

```
瀏覽器 → Vite 開發伺服器 localhost:5173（/admin/ 後台）、localhost:5174（主站：公開查書頁）
       → /api 轉發到 → .NET API localhost:5080
       → MySQL（Docker 容器 lobsang-mysql，127.0.0.1:3306，資料庫 Lobsang）
       → 上傳檔案：C:\Han\Lobsang\uploads
```

| 東西 | 位置 |
|---|---|
| MySQL 設定 | `deploy/local/docker-compose.yml`（MySQL 8.4，utf8mb4_0900_ai_ci，只開放本機連線） |
| MySQL 資料 | Docker volume `local_lobsang-mysql-data`（刪容器資料還在，刪 volume 才會不見） |
| 資料庫帳密 | `deploy/local/.env`（範本：`deploy/local/env.example`），帳號 `lobsang` |
| API 設定 | `API/Lobsang/appsettings.Development.json`：連線字串、JWT 金鑰、上傳路徑、快速登入清單、Google Books 金鑰（`BookLookup:GoogleApiKey`，選填） |
| 環境 | `ASPNETCORE_ENVIRONMENT=Development`（`launchSettings.json` 的 `http` 設定檔） |

> ⚠ `.env` 和 `appsettings.Development.json` 都**不進 git**。兩邊的資料庫密碼要一致，改了一邊另一邊也要改。

### 啟動（每次開機後）

```bash
# 1. 資料庫（Docker Desktop 要先開著；容器設定成 Docker 啟動時自動起來）
cd deploy/local && docker compose up -d
# 2. API → http://localhost:5080
cd API/Lobsang && dotnet run --launch-profile http
# 3. 後台 → http://localhost:5173/admin/
cd ReactAdmin && npm run dev
# 4. 主站（公開查書頁）→ http://localhost:5174/
cd React && npm run dev -- --port 5174 --strictPort
```

> ⚠ 本機的主站和後台是不同埠號，所以主站頁尾的「後台」連結（`/admin/`）在本機打不開，要自己開 5173。上了開發站之後兩個在同一個網址，就正常了。

### Google Books API 金鑰（查書用，**還沒申請**）

沒有金鑰時，伺服器查 Google Books 是跟全世界沒金鑰的人共用免費額度，幾乎一直回 429「額度用完」。
⇒ 歐美書只剩 Open Library 一個來源，新書常常查不到（例：2026-11-07 查 `9780241833162`，Penguin UK 的書，Google 額度用完、Open Library 三種查法都沒有）。

| 項目 | 說明 |
|---|---|
| 費用 | **免費**。Books API 沒有付費方案，超過額度只會當天查不到，不會收費 |
| 額度 | 每個專案每天約 1,000 次；查到的結果伺服器會快取 6 小時，同一本書重複查不重算 |
| 信用卡 | 一般不用綁。Google Cloud 第一次登入推薦的「免費試用」是給其他付費服務用的，可以跳過 |
| 放哪裡 | 本機：`appsettings.Development.json` 的 `BookLookup:GoogleApiKey`（不入版控）；開發站：VM `.env` → compose 環境變數 `BookLookup__GoogleApiKey` |

申請步驟（要用業主自己的 Google 帳號）：
1. 開 https://console.cloud.google.com/ 登入
2. 上方建立專案（例如 `lobsang`）
3. 「API 和服務」→「程式庫」→ 搜尋 **Books API** →「啟用」
4. 「API 和服務」→「憑證」→「建立憑證」→「API 金鑰」，複製 `AIza…` 開頭的金鑰
5. 建議在金鑰設定裡「限制金鑰」只能用 Books API（外流也只能拿來查書）
6. 填進設定後重開 API（重開也會清掉舊的查詢快取）

> ⚠ 費用與額度是 2026-11-07 依 Google 的方案說明整理，申請時以畫面為準；看到任何要收費的字樣先停下來確認。

### 換一台電腦要準備的

- Docker Desktop
- .NET 8 SDK（`winget install Microsoft.DotNet.SDK.8`）和 `dotnet tool install --global dotnet-ef --version "8.*"`
- Node.js（這台是 Node 26／npm 11）；`ReactAdmin` 第一次執行 `npm ci`
- 把 `deploy/local/env.example` 複製成 `.env` 填密碼，再照 Base 的 `appsettings.Development.json` 格式建一份（連線字串改 `Server=127.0.0.1;Database=Lobsang;Uid=lobsang`）

### 重置資料庫（清空重來）

```bash
cd deploy/local && docker compose down -v   # ⚠ -v 會連資料一起刪掉
docker compose up -d                        # 再啟動 API，會自動建表、種示範資料
```
