# Lobsang

## 還沒做的

- 開發站 f66.io 的安全強化（業主還沒決定）：Cloudflare 到主機這段改走 HTTPS（Origin 憑證＋Full (strict)）；防火牆 80／443 只開給 Cloudflare 的 IP
- 確認公開查書的限流拿到的是使用者真正的 IP（f66.io 經過 Cloudflare 和 nginx 轉送，沒設好會變成所有人共用一個「每分鐘 20 次」）
- 用真的手機實測「📷 掃描」和後台「連續掃描」
- 書單裡已經有的書存的是加入當時的資料：要換成誠品第 1 順位的資料，要在後台重查一次再按「更新書單裡的資料」
- EliteCrawler 匯入的 `openbd_books`（日本書目）已用在查書；要不要讓公開頁也能直接搜尋這 195 萬筆，業主還沒決定
- 機構正式名稱：目前先用「Lobsang」，之後可以在資料庫或畫面上改
