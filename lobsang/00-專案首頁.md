# Lobsang

> 合滙科技的新專案，2026-11-07 從 **Base**（基礎後台＋API 範本，commit `d7a4f96`）複製出來。
> 登入、權限、簽核、表單引擎這些共用功能都是 Base 帶來的；這個專案只要做自己的業務模組。

## 一眼看懂

| 項目 | 內容 |
|---|---|
| 目前狀態 | 本機開發；開發站 f66.io 架在 GCP uni-maindb-prod（見 [[03-環境與部署]]） |
| 程式 | `C:\Han\Lobsang`；git：https://github.com/vintageamy-maker/lobsang.git（分支 `main`） |
| 技術 | .NET 8 Web API ＋ EF Core（MySQL，Pomelo）＋ React 18／Vite／antd 後台 |
| 公開查書頁 | http://localhost:5174/（不用登入） |
| 後台 | http://localhost:5173/admin/ |
| API | http://localhost:5080（swagger：`/swagger`） |
| 資料庫 | 本機 Docker 容器 `lobsang-mysql`（MySQL 8.4），資料庫 `Lobsang` |
| 檔案 | 存本機 `C:\Han\Lobsang\uploads` |
| 示範帳號 | `admin`（系統管理員，`Lobsang#2026`）、`manager01`（王主管）、`staff01`（陳同仁）都是 `Test#2026`。登入頁有快速登入 |
| 業務模組 | 查書與書單（見 [[01-模組與架構]]） |
